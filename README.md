# 차근 — 나의 작은 일정

오늘 할 일을 중심으로 사용하는 모바일 대응 일정 체크 앱입니다. 별도 설치나 서버 계정 없이 동작하며, 외부 CDN/API를 사용하지 않습니다.

## 실행

```sh
cd /workspace/sparta
python3 -m http.server 8000 --bind 127.0.0.1
```

일반 배포에는 이 폴더의 `index.html`, `style.css`, `app.js`를 정적 웹 호스팅에 올리면 됩니다. 모바일에서는 배포된 HTTPS 주소로 접속할 수 있습니다. 현재 클라우드 환경의 로컬 서버는 공개 배포가 아닙니다.

## 사용

- 오늘 할 일 추가, 선택 시간 입력, 완료 체크와 진행률 표시
- 주간·월간 보기 및 날짜별 일정 선택
- 일정 제목을 눌러 이름·날짜·시간 수정, 삭제 후 10초 내 되돌리기
- 아침 계획, 진행 확인, 하루 마무리를 돕는 자동 응답 체크인
- 아침 계획에서 오늘의 첫 할 일을 대화로 기록, 또는 `할 일: 산책하기`처럼 입력해 일정 추가
- 페이지를 열어둔 동안 동작하는 15분 집중 타이머
- 날짜별 일기와 날짜에 관계없이 모아보는 업무 메모 (작성 중 내용 자동 저장)
- 할 일·일기·메모 전체 백업 및 기존 기록과 병합 복원
- 일정 제목 18px, 본문 16px 중심의 편안한 중간 글씨 크기

일정·일기·메모는 해당 기기의 해당 브라우저 localStorage에 저장됩니다. 같은 주소라도 PC와 모바일 간 자동 동기화는 되지 않습니다. 브라우저 데이터를 삭제하면 일정도 삭제되므로 백업을 권장합니다. 대화 기록과 집중 타이머는 새로고침하면 초기화됩니다. 체크인은 규칙 기반 자동 응답이며 생성형 AI, 실제 동료 연결, 푸시 알림 기능은 포함하지 않습니다.

## 검증

Chromium/Playwright로 일정 추가·시간 입력·체크·진행률·새로고침 후 유지·수정·삭제 복구·주간/월간 이동·체크인·집중 타이머·대화·모바일 가로 넘침 및 사용자 입력 HTML 처리 방지 기능을 확인했습니다.


## Windows 바탕화면 바로가기

`desktop/windows`의 파일을 함께 압축 해제하고 `Install.cmd`를 실행합니다. 현재 사용자의 `%LOCALAPPDATA%\Chageun`에 단일 HTML 앱을 복사하고 바탕화면에 `차근.lnk`를 생성합니다. Edge 또는 Chrome의 전용 프로필(`BrowserProfile`)과 앱 창을 사용하며 서버·로그인·관리자 권한이 필요하지 않습니다. 설치 파일은 네트워크 다운로드나 시스템 정책 변경을 하지 않습니다. 업데이트는 HTML 파일만 교체하고 프로필은 유지합니다. 설치는 Windows에서 실행해야 하며 Linux 제작 환경에서는 Windows 설치 실행을 검증하지 못했습니다.

차근 아이콘 변경

1. ZIP 파일을 모두 압축 해제합니다.
2. Change-icon.cmd를 두 번 클릭합니다.
3. 바탕화면의 차근 아이콘을 확인합니다. 이전 아이콘이 남아 있으면 바탕화면을 클릭하고 F5를 누릅니다.

기존 차근 설치를 확인한 후, 차근 전용 바로가기의 아이콘만 바꿉니다.
일정·일기·메모와 BrowserProfile 폴더는 변경하지 않습니다.
설치 폴더의 예비 바로가기에도 같은 아이콘을 적용합니다.

수동 변경: chageun-icon-v1.ico를 %LOCALAPPDATA%\Chageun 폴더에 복사한 후, 바탕화면 차근을 오른쪽 클릭 > 속성 > 바로 가기 > 아이콘 변경 > 찾아보기에서 복사한 ICO 파일을 선택하세요.

아이콘 파일은 Windows ICO 규격과 여러 해상도를 검증했습니다. 설치/변경 스크립트는 Linux 제작 환경에서 작성했으며 Windows에서 실제 실행은 검증하지 못했습니다.

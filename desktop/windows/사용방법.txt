차근 — 오늘 할 일 (Windows)

1. 다운로드한 ZIP 파일을 마우스 오른쪽 클릭하고 '모두 압축 풀기'를 선택하세요.
2. 압축을 푼 폴더에서 Install.cmd를 두 번 클릭하세요.
3. 바탕화면에 '차근' 바로가기가 생성되고 앱이 열립니다.
4. 앞으로는 바탕화면 '차근'을 두 번 클릭하면 됩니다.

Microsoft Edge를 우선 사용하고, 없다면 Google Chrome을 사용합니다.
관리자 권한이나 별도 서버 설치, 계정, 인터넷 연결은 필요하지 않습니다.
기존에 같은 이름의 다른 바로가기가 있으면 덮어쓰지 않고 설치를 멈춥니다.

일정은 이 PC의 전용 브라우저 저장 공간에 자동 저장됩니다.
저장 위치: %LOCALAPPDATA%\Chageun\BrowserProfile
앱 파일: %LOCALAPPDATA%\Chageun\chageun.html
새로 실행하면 그날의 일정이 기본으로 보입니다.
PC와 휴대폰 간 자동 동기화는 없습니다. 같은 Windows 계정을 사용하는 사람은 앱을 열 수 있습니다.

앱 하단의 '전체 백업'으로 할 일·일기·업무 메모를 함께 저장하세요.
일기는 일정 날짜를 선택해 날짜별로 작성합니다. 업무 메모는 날짜에 관계없이 모아볼 수 있습니다.
일기, 메모와 작성 중 메모는 입력할 때 자동 저장됩니다. 저장 실패 안내가 뜨면 닫기 전에 전체 백업으로 보관하세요.
다른 PC로 옮길 때는 새 PC에 앱을 설치하고 '백업 불러오기'로 백업 파일을 선택하세요.
앱을 업데이트할 때는 기존 차근 창을 닫고 새 ZIP을 압축 해제한 뒤 Install.cmd를 다시 실행하세요.
같은 앱 경로와 전용 프로필을 사용하므로 기존 일정·일기·메모 저장 공간은 유지됩니다.
이 폴더의 BrowserProfile을 삭제하거나 해당 전용 브라우저 데이터를 지우면 일정이 없어집니다.

전용 브라우저 창에서 동작하는 웹 앱입니다.
체크인 대화는 규칙 기반 자동 응답이며 실제 사람 또는 생성형 AI와 연결되지 않습니다.
대화와 집중 타이머는 앱을 다시 열면 초기화됩니다.

일정 추가·체크·저장·백업 복원 기능은 Chromium으로 검증했습니다.
설치 파일은 Windows용으로 작성했지만 제작 환경은 Linux라 Windows에서 실제 설치 실행은 검증하지 못했습니다.
Windows 조직 정책으로 PowerShell/로컬 HTML 실행이 차단된 PC에서는 설치가 동작하지 않을 수 있습니다.


바로가기 위치 확인 (2026-10-15 수정 설치 파일)

앱은 열리는데 바탕화면 아이콘이 보이지 않으면, 바탕화면 빈 곳을 오른쪽 클릭하고
보기 > 바탕 화면 아이콘 표시가 체크되어 있는지 확인하세요.

수정 Install.cmd는 Windows가 알려주는 실제 바탕화면 경로(OneDrive 리디렉션 포함)에 바로가기를 만들고,
완료 후 탐색기에서 그 바로가기를 선택해 보여줍니다. 설치 창도 자동으로 닫히지 않습니다.

설치 폴더에도 예비 바로가기 Chageun.lnk를 만듭니다.
Windows 키 + R을 누르고 %LOCALAPPDATA%\Chageun 을 입력해 폴더를 열 수 있습니다.
기록이 있는 BrowserProfile 폴더는 수정하거나 삭제하지 않습니다.

설치 로그: Windows 키 + R에서 %TEMP%\Chageun-Install.log
성공 결과: %LOCALAPPDATA%\Chageun\Install-result.txt
오류가 나면 메모장으로 로그를 열어줍니다. 사용자 PC의 경로가 포함되므로 필요한 오류 부분만 공유하세요.
수정 설치 파일은 제작 환경에서 구조와 압축 파일 검증을 했으며 Windows에서 실제 실행은 아직 검증하지 못했습니다.
